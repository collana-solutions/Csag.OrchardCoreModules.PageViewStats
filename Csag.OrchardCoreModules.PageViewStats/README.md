# PageViewStats

Just reference the NuGet package in your OrchardCore project and then activate it in the features of your backend.

In recipes, the feature ID is `Neolution.OrchardCoreModules.PageViewStats`. Orchard Core takes it from the assembly name, and sites store it, so it differs from the package ID.

See the [repository](https://github.com/collana-solutions/Csag.OrchardCoreModules.PageViewStats) for details.
